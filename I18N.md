# Multilingüe (ES, DE, EN, FR)

## Dónde editar textos

| Qué | Archivos |
|-----|----------|
| Interfaz, navegación, páginas, galerías (títulos), formularios, vídeos | `_i18n/es.yml` y los mismos keys en `de.yml`, `en.yml`, `fr.yml` |
| Reseñas Bodas.net | `_data/reviews/es.yml` (+ `de`, `en`, `fr`) |
| Aviso legal / cookies / privacidad | `_data/legal/es.yml` (+ `de`, `en`, `fr`) |
| Rutas (no traducir) | `_data/routes.yml` |
| Listado de galerías (slug + URL) | `_data/galleries.yml` |
| Bloques inicio (imagen + URL) | `_data/home-blocks.yml` + textos en `i18n` → `home_blocks` |

Mantén **la misma estructura de claves** en los cuatro YAML de cada grupo.

## URLs

- Español (por defecto): `/biografia/`, `/galerias/`, …
- Alemán: `/de/biografia/`, …
- Inglés: `/en/…`
- Francés: `/fr/…`

El selector de idioma y los `hreflang` en `<head>` enlazan la misma página en cada idioma.

## Añadir una galería nueva

1. Carpeta de imágenes en `assets/images/galleries/<slug>/`
2. Entrada en `_data/galleries.yml` (`slug` + `url`)
3. Título (y descripción opcional) en `galleries.<slug>` dentro de los cuatro `i18n/*.yml`
4. Página en `galerias/<slug>/index.md` con `gallery_folder: <slug>`

## Build

```bash
bundle install
bundle exec jekyll build
```

Usa [jekyll-multiple-languages-plugin](https://github.com/kurtsson/jekyll-multiple-languages-plugin) (`plugins` en `_config.yml`). Los estáticos van en `exclude_from_localization` (p. ej. `assets`) para que CSS/JS/imágenes no se copien por idioma.
